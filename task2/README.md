# 三个swap函数
1. 传值：交换的是副本，原变量不受影响（将实参拷贝出来交换，交换后副本自动销毁，所以传值交换不了）
2. 传指针：通过地址间接修改原变量
3. 传引用：a、b 就是原变量的别名，直接修改

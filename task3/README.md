## 灯条类
成员：灯条中心点，灯条长度，灯条宽度，倾斜角，颜色

职责：描述一根灯条的几何与颜色属性

## 装甲板类
成员：构成装甲板的两根灯条，装甲板中心点

职责：由两根灯条组合而成，提供装甲板级别的几何信息与配对合理性判断。

## Detector类
成员：纯虚函数：输入灯条集合，返回配对成功的装甲板列表；纯虚函数：派生类声明自己识别的目标颜色；检测器名称（用于输出显示；protected 公共配对逻辑：按颜色筛选，两两构造 Armor，条件为"平行 + 中心间距 ∈ [30, 200]"

职责：定义检测器的统一接口（纯虚函数 detect()），并把"筛选同色灯条 → 两两配对 → 条件过滤"的公共流程封装在基类，避免红蓝两个派生类重复代码。
